Lunar-Route-Planner documentation
=================================



This project is meant to provide a way to find the best route between 2 points on the moon using SLDEM lunar elevation data, 
that can be found at the `Lunar Orbital Data Explorer <https://ode.rsl.wustl.edu/moon/download>`_ website.

For a quickstart, see :class:`main.RoutePlanner` annd :class:`utils.SLDEM_reader`.

Full API documentation can be found at :doc:`api/modules`

Source code can be found in the `GitHub repo <https://github.com/Elvin-Hadi-0006/Lunar-Route-Planner>`_.
