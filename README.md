# LOLA Route Planner
This is the final project for MMA3001 - Numerical methods and machine learning. This project is meant to create a route finding algorithm based on the Lunar Elevation Digital Map (LDEM) provided by Lunar Orbital Laser Altimeter (LOLA) on the Lunar Reconnaissance Orbiter.

# Training Data
The model has been trained on the ldem_1024_00n_15n_300_330 dataset, that can be downloaded from the Lunar Orbital Data Explorer website (https://ode.rsl.wustl.edu/moon/).
